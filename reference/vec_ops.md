# Vector ops

Vector ops

## Usage

``` r
vec_neg(x)

vec_exp(x)

vec_expm1(x)

vec_log(x)

vec_log1p(x)

vec_m_from_q(x)

vec_add(x, y)

vec_sub(x, y)

vec_mul(x, y)

vec_div(x, y)

vec_pow(x, y)

vec_min(x, y)

vec_max(x, y)

vec_clamp(x, min, max)
```

## Arguments

- x:

  A vector of double.

- y:

  A vector of double.

- min, max:

  Vectors of double for the `clamp` operation.

## Value

A vector of `double`.
