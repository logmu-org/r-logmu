# Add or assign a data column

Add or assign a data column to `exp_data` or `val_data`.

## Usage

``` r
# S3 method for class 'exp_data'
x$name <- value

# S3 method for class 'val_data'
x$name <- value
```

## Arguments

- x:

  The `exp_data` or `val_data`.

- name:

  The `name` of the column to assign.

- value:

  The column values.

## Value

The updated `exp_data` or `val_data`.
